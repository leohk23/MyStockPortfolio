# Reviews

One file per Review run, `YYYY-MM-DD-HHMM.md` in UTC. Each re-reads every **accepted** thesis
against the warning and break conditions the proposal committed to, and produces a SELL or TRIM
instruction only where §5.1 allows one.

Written by `pot/brief-review.md`. The arithmetic it works from is in `signals.json` under
`6.5 thesis review`; the judgement is the lane's own.
